はじめに

このガイドについて

相手にリーチされて自分もテンパイに追いついたとき、押すかオリるかを、点数と祝儀の見込み（期待値）で決めるためのガイドです。

大手フリー雀荘で多い青入りの三人麻雀ルールに合わせて、押し引きを計算した資料は多くありません。そこで、このルールでシミュレーションを行い、このガイドを作りました。

このルールではリーチが基本の戦術で、しかも打点が高いので、判断はかなり押し寄りになります。そのうえで、押し引きのうち判断に迷う場面を抜き出し、似た場面ではどこが損益分岐点になるかを、表とケーススタディで確かめます。細かい条件の違いは、付属の Excel の計算機で確かめられます。

ある程度打てる人向けです。牌効率の解説はありません（一向聴での押し引きは、ケーススタディと鳴きの章で扱います）。章の並びは、基本（リーチの強さ・両面ならほとんど押せる・待ち牌が相手の現物のとき）→ 判断に迷う8つの場面 → 判断の流れと計算機 → ケーススタディ → 鳴きがからむ場面 → 詳細データ編です。

計算したルール（大手フリーの三麻ルール）
  • 35,000点持ち40,000点返し、ウマ+20/0/−20、トビ賞あり、ツモ損なし。ウマ・オカがあるので、点の増減は約1.9倍して比べます（このガイドでは「着順の重み」と呼びます）
  • 5筒・5索は4枚ともドラ（赤3枚・青1枚）。抜いた花も1枚1翻（鳴いた手でも数える）
  • 祝儀は一発・裏ドラ・青（青5筒・青5索・青の花）に各1枚。祝儀1枚＝5,000点として計算。祝儀1枚の重さはお店によって違うので、計算機で変えられる
  • 30符固定（七対子も30符）、4翻30符は満貫に切り上げ。フリテンリーチなし
  • 和了した手には、5が平均1.8枚、花が平均1.0枚入る（シミュレーションの値）。相手のリーチの和了は平均で約6翻

ほかのルールのお店向けに作り直したガイドが必要な場合は、ご相談ください。

このあとのページに共通することを、ここにまとめます。
得点期待値と失点期待値

押したときの期待値は、自分の和了による得点期待値から、放銃とツモられによる失点期待値を引いたものです。得点期待値には、リーチの1翻・一発・裏ドラと、それぞれの祝儀、リーチ棒を入れています。オリたときも、ツモられる分と、安全な牌が足りずに放銃する分を失点期待値に入れています。

着順も入れて計算

点数はすべて、ウマ・オカで順位の点が動く分を入れた値です。

何翻あれば押せるか（損益分岐点）

押す方とオリる方の期待値が同じになる境目を、損益分岐点といいます。このガイドでは、その境目を「何翻あれば押せるか」で示します。翻数は和了したときの翻数で、リーチの1翻も入れて数えます。少ない翻数で押せる所ほど緑、多くの翻数が要る所ほど赤にしています。

このあとの表の「◯翻から」は、どれも同じ計算で出しています。1つの場面で、その中身を見ます。

基本 リーチの強さ

役があってもリーチが基本です。相手のリーチに両面で追いついたときも、相手の打点がよほど高くない限り、追っかけリーチで押します。ダマで6翻（跳満）が確定していると、ダマの和了率がリーチの1.5倍あればダマが上回るところまで差が縮みます（表の外の翻数も同じ計算で確かめました）。ダマで満貫（4翻）なら、まだリーチの方が有利です。

リーチの方が得な理由

同じ牌を切るので、放銃の危険はリーチでもダマでも同じです。違うのは和了したときの点で、リーチで足される1翻・一発・裏ドラと、その祝儀が効きます。

祝儀1枚の重さは計算機で、ほかの数値は Excel の「前提」シートで変えられます。

計算の前提

1巡ごとに「相手のツモ和了 → 他家の捨て牌で自分がロン → 自分のツモ和了 → 自分の打牌で放銃」の順に確率を進め、押した場合とオリた場合の点数の見込みを比べています。 相手のリーチの打点は満貫ではなく、平均の約11,300点（親は約16,900点）です。オリても、安全な牌が足りずに放銃することがあります。その割合は、手の中の安全な牌の枚数と巡目ごとに測り、計算に入れています。 牌の危険度は、相手を強い打ち手と想定し、ネット麻雀の上級者の実戦に合わせて測りました。 点数には、着順の重み（ウマ・オカで約1.9倍）を掛けています。各章の数字は、特に書いていなければ子どうし・東場・祝儀1枚5,000点ぶんで計算しています。

計算機の「点」は、素点に着順の重み（東場・ふつうで約1.9倍）を掛けた値で、祝儀には重みを掛けていません。和了率は、公開されている集計の5巡目の愚形リーチの和了率（四人麻雀の値）に合わせ込んでいます。 押すときは「その後ずっとツモ切り」、オリるときは「今すぐ完全にオリ」の2つだけを比べていて、ダマで途中からオリる選択肢は入れていません（ダマの点は実際より低く出ます。「待ち牌が現物のとき」の2ページだけは入れています）。2人リーチのときは、自分が子なら相手の1人を親・1人を子として、自分が親なら相手の2人を子として計算しています。リーチした2人はツモ切りなので、自分がロンできる機会も2人分として数えています。 押し引きの計算では、リーチしていないもう1人の相手（以下、3人目）は和了しない、としています（危険度の測定には、鳴いて押す3人目を入れています）。「待ち牌が現物のとき」の2ページでは、3人目が現物を切る分も入れています。3人目の和了を入れると、待ち3枚で必要な翻数が0〜1翻増える見込みです。親の連荘は表に入れていません。親が1局続く価値（東場、着順込み）は、自分の親なら約2,100〜3,200点の得、相手の親なら約1,300〜1,700点の損でした。これを入れると、自分が親で待ち3枚なら必要な翻数が0〜1翻減ります。相手が親でも少し押し寄りになりますが、必要な翻数はほとんど変わりません。 役の無いダマ（ドラ・5・花だけ）は、門前ツモだけで計算しています。リーチ棒・供託にも着順の重みを掛けています。 計算機で扱えるのは、門前でテンパイしているときだけです。
